# 产品定义

## 已确认方向

Weave 是统一的个人工作空间，核心定位为写作、备忘和待办。技术、界面和交互重新设计。

- 使用 Swift 原生技术，面向 Mac、iPad 和 iPhone，保持单仓库。
- 数据由 App 管理，本地优先，通过 CloudKit 同步；不以用户管理的 Markdown 文件夹作为主要存储。
- 同一 Apple 账户的新设备可恢复已上传内容；未上传数据仍依赖原设备。
- 记录可以嵌入画板与思维导图预览，进入独立编辑区修改可编辑内容。
- 多设备同步服务于个人连续使用；实时多人共同编辑不属于当前确认范围。

以上为长期方向。当前第一期仅实现本地基础富文本与 Markdown 排版，CloudKit 与画板尚未实现。

## 已确认工作区结构

宽窗口使用「综合侧栏 + 内容区」两栏。侧栏上部为记录、任务等功能入口，下部为该功能独立的分类与常用视图。记录和任务不共享分类。Mac 与宽窗口 iPad 对齐，窄窗口 iPad 与 iPhone 对齐，按可用空间适配。布局和材质边界见 [DESIGN](../DESIGN.md#工作区布局已确认方向)。

当前 Mac 与 iOS/iPadOS 均提供记录导航、分类及浏览与编辑。独立任务和折叠屏专项适配仍为后续方向。

## 待设计与验证

各功能细节、附件离线策略和回收站保留策略仍需后续设计。Markdown 文件导入导出已纳入当前编辑器范围。
详见[第一版交互草案](specs/first-release.md)。用具体流程与验收场景收敛问题，避免一次性扩展成完整办公套件。
