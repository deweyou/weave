## 维护方式

行为变化更新本期规格；数据或模块边界变化更新架构；视觉与交互决策更新 DESIGN；新发现的回归场景更新验证清单。入口或命令变化同步修改关联链接和配置。

每项结论标明“现状”“方向”或“待验证”。当前知识不记流水账、历史失败日志或已放弃方案；任务推理和执行证据保留在任务记录 / Run 中。引用代码用文件和符号，避免容易漂移的行号。新增独立决策文档只用于有长期影响的取舍，不为小修复制造文档层级。
