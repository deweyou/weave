# 第一期：原生文本编辑器与基础富文本

用户已收敛第一期范围：干净、简单的文本编辑，遵循 Apple 设计原则，使用系统控件与 Liquid Glass。

## 本期实现

- 记录列表与正文编辑区；窄窗口由系统导航适配。
- 新建空记录后输入；不要求标题或分类，第一条非空行作为标题。
- 系统富文本原生编辑区，格式菜单、字符统计、原生选区与编辑菜单。
- 搜索记录，Mac Command-N 新建。
- 修改后本地原子保存，重启恢复；损坏文件禁写，保存失败提示重试。
- Mac、iPhone、iPad 共享源码，以系统 26 为当前基线。

没有固定品牌色或自制玻璃控件；正文不使用玻璃背景。读取出错保留源文件，只有明确的重新读取动作可以重试。

## 富文本增量

已实现加粗、斜体、下划线、删除线、标题、等宽字体及格式保存恢复。
Markdown 菜单明确转换选区或全文，支持常用标题、行内样式、链接、代码、列表和引用。转换替换原文，可撤销；不在中文组合输入时自动替换。
列表和勾选项为文本标记，支持无序列表和引用续行，尚无嵌套结构和交互待办。全文转换会重置既有样式，不提供 Markdown 无损往返。
测试覆盖真实样式与链接持久化、旧纯文本兼容、损坏富文本保护、格式撤销重做和 Markdown 中文语法。

## 后续范围

删除与回收站、待办关联、CloudKit、画板和思维导图不在本期实现。长期产品方向见[产品定义](../product.md)。

## 验证

存储测试覆盖中文多记录恢复、稳定 ID、损坏文件禁写和写失败重试。Mac App 和 iOS Simulator target 分别编译。
真实交互应检查新建、输入、撤销重做、切换记录与重启恢复；中文输入法组合态、VoiceOver 和减少透明度需单独观察，不以编译代替。
当前 JSON 全量同步保存用于小规模文本起步，不承诺大规模笔记库性能或云端同步。
